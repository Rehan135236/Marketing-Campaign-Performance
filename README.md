# 📊 Marketing Campaign Performance Dashboard

## 📌 Overview
This project presents a **Marketing Campaign Performance Dashboard** built using Power BI and Excel to analyze key marketing metrics such as revenue, cost, ROI, and conversions across multiple channels.

The dashboard helps in identifying performance trends, evaluating channel effectiveness, and optimizing marketing strategies.

---

## 🚀 Features
- 📈 KPI Tracking (Revenue, Cost, ROI, CPA, Conversions)
- 📊 Channel Performance Analysis (Display, Email, Influencer, Search, Social)
- 📅 Monthly Revenue & Cost Trends
- 🧮 ROI Comparison by Channel
- 🔍 Conversion Funnel Analysis
- 💰 Cost Distribution Insights
